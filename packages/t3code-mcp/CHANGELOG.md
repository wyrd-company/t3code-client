# Changelog

## 0.1.1

### Fixes

- Publish the complementary MCP server and its setup documentation under an available npm version.

## 0.1.0

### Features

- Provide the t3code-mcp stdio MCP server, complementing stock T3 Code MCP with scheduled task endpoints, webhook rotation and deliveries, execution configuration, thread status, approvals, usage, diffs and in-thread search, provider status and usage summaries through shared t3c profiles. Include native thread Stop, queue Resume and selected queued-message Start. Resume and selected Start clear the hold on all queued runs; other messages may follow.
