# @wyrd-company/t3code-lib

TypeScript client for the [T3 Code](https://github.com/pingdotgg/t3code) server. This is an
independent project, not part of T3 Code.

- Typed access to the HTTP API, WebSocket RPC, commands and auth control plane.
- `Promise` and `AsyncIterable` surface, with no Effect dependency.
- Forward compatible with newer servers.

```bash
pnpm add @wyrd-company/t3code-lib
```

Read the [quick start](https://wyrd.foo/docs/t3c/guide-quick-start), the other library guides and
the [API reference](https://wyrd.foo/docs/t3c/library-reference).
