# Changelog

## 0.3.0

### Features

- Organize the generated library API into developer reference pages and add a t3c command-prompt SVG icon.
- Document native thread Stop, queue resume and selected queued-message start in the CLI and complementary MCP server.
- Add thread find with provider and native session inputs, returning a T3 Code thread ID or null.
- Document complementary MCP tools, scheduler endpoints and delivery diagnostics, structured thread inspection, model options and workspace selections, provider status and historical usage.
